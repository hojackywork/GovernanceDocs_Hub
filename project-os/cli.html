ProjectOS CLI 工具說明

以下 help 來自同版公開 parser；詳細參數用對應子命令 --help。工作流程、必要前提、approval 與 executor_policy 另由同版 get_workflow 查詢。既有登入／人工批准不可用文件查詢代替；不增加操作權。

usage: project-os [-h] [--version]
                  {git-doctor,init,reconcile,audit,watch,mcp,docs,skills,deploy,setup,undeploy,teardown,status,governance,release,inbox,intake,providers,lock,preflight,testhook,brief,schemas,discipline,pause,resume,doctrine,scope,concept-review}
                  ...

Naming & Storage Governance —— 唯一保證來自事後 reconcile

positional arguments:
  {git-doctor,init,reconcile,audit,watch,mcp,docs,skills,deploy,setup,undeploy,teardown,status,governance,release,inbox,intake,providers,lock,preflight,testhook,brief,schemas,discipline,pause,resume,doctrine,scope,concept-review}
    git-doctor          一鍵雙層 git 遷移（預設偵測即修；--plan 零寫入預覽）
    init                初始化受管專案佈局與 .project-os/config.toml
    reconcile           執行治理（最終保證，可隨時手動跑）
    audit               工程紀律事後審計（只讀 git 歷史，只報告不阻擋）
    watch               檔案監聽（best-effort 加速器；最終保證仍是 reconcile）
    mcp                 MCP stdio server（MCP 共 27：Read 19／Draft Write
                        8；Read不持久寫入；Draft只起草未生效草稿，不採納不執行。）；子命令
                        install/uninstall/list＝一鍵接入本機 AI hosts
    docs                車載文件（FAQ／GLOSSARY／AGENTS 模板，隨 wheel 發行；人類讀者維持讀工廠）
    skills              車載 skill 部署（SKILL_HOSTS 閉集；子命令
                        install/uninstall/list＝冪等部署到本機 host skills 目錄，衝突只報告）
    deploy (setup)      部署精靈（自動部署＋清舊 Connector 註冊＋GUI 指引＋session
                        提示詞；舊名 setup）
    undeploy (teardown)
                        解除部署精靈（移除各 Host 部署＋遺留清掃；UI 側給指引；舊名 teardown）
    status              部署狀態總覽（版本／最新版／各 Host 三件套；--json 機讀輸出）
    governance          governance 採納文件（F-3；type 閉集五值 fail-closed）
    release             發佈流水線裝配（乙案：只產中央模板呼叫檔，不擁邏輯）
    inbox               inbox 人工工作流（F-5：list/show/enroll/approve）
    intake              首納管工作流（Q1b：人審後機制化關閉保護）
    providers           Provider adapter 介面（Slice 4）
    lock                諮詢鎖（互斥提示層，advisory 不阻擋）
    preflight           交付前檢查（綠燈宣稱的機械鏡子）
    testhook            M-1 測試對賬掛鉤配送（把 pytest_sessionfinish 產物掛鉤寫入
                        <primary>/tests/conftest.py，受管專案自產 audit 規則 4
                        證據；冪等、--plan 預覽）
    brief               開工簡報（你缺席期間的規則變更＋環境狀態）
    schemas             schema 閉集索引（Q1：何處有 schema、誰消費它）
    discipline          紀律標記腳手架（按底座型態追加 opt-in 驗證段，既有不覆寫）
    pause               維護窗口（）：暫停 reconcile 執行面 N
                        小時——只報告不搬移、觀測不停、到期自動恢復。**人獨有操作**
    resume              提前結束維護窗口（人獨有操作）
    doctrine            教義（M-7，每個專案自己的教義檔與修正案鏈——機制均等，非引擎倉專有）
    scope               MVP 邊界（，2026-11-12 裁決批一
                        Q7）：封存只認 scope seal 命令的記錄——自封不生效
    concept-review      概念層交叉審核（M-10，OpenRouter
                        三模型紅隊、排除宿主家族、一家紅即申報——LLM 判定＝信號非保證）

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit

intake.mkdir

建立目標目錄

mkdir -p <路徑>

必要前提：此流程無額外宣告前提；仍需既有批准與可用Host

效果：formal-write；執行者：human-or-ai；批准：human-review；提供狀態：available

intake.initialize

建立受管配置及底座（init）

project-os init --project <路徑> --primary <型別>

必要前提：目標路徑已選定；未受管（已受管轉日常治理，停止）

效果：formal-write；執行者：human-or-ai；批准：human-review；提供狀態：available
