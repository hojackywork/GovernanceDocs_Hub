ProjectOS Plugin 工具說明

27 枚工具：Read 19／Draft Write 8；Read 零落盤，Draft Write 僅未生效草稿、不採納不執行。正式操作依批准走 CLI／人工。

project-os 是專案執行入口；project-os-guide 是中立指引，不操作專案。完整操作目錄含 CLI／人工；blocked 是不可用候選，不屬可呼叫工具。

本地 stdio 需要已部署引擎；ChatGPT 雲端無法啟本機 stdio；包、Host 安裝、頁面與新聊天載入分開驗收。
